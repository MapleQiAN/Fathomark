AAPL 高保真成品：最终设计确认

视觉采用 B“现代研究工作台”，交互采用 C“阅读器 + 模拟实验区”。

Recommended architecture

Markdown 完整正文 + 结构化增强层

原始 MD→章节与表格解析→完整 HTML→同页打印 PDF

原稿是正文事实源，所有 20 个章节、段落、列表、表格与两张图片逐项保留。评分、情景和估值表再增加结构化视觉组件，但不替换原文。

专业阅读器

固定目录、全文搜索、阅读进度、章节折叠、亮暗主题、表格与图表切换。

独立模拟区

调整 EPS、终值 P/E、股息与概率；明确标注“实验”，一键恢复原报告参数。

专业 PDF

A4 封面、目录、页眉页脚、页码、跨页表头和防孤行；完整正文与原始图表。

离线单文件

图片、样式和脚本全部内嵌，不依赖网络；HTML 可直接归档和分享。

正式报告数值与模拟结果分层。PDF 固化原报告数据；交互实验不会覆写 79.60、B+ 或原始五年情景。
Approaches considered

1. 直接美化 Markdown

开发最快，但难以提供丰富交互和专业数据层级。

2. 全部手工重建

视觉自由度最高，但容易遗漏原稿内容，也会制造两套事实来源。

3. 完整正文 + 增强层

推荐。完整性、可审计性与视觉表现最平衡；同一份内容生成 HTML 和 PDF。

视觉基线

暖白背景、石墨黑正文、单一青绿色强调；中文无衬线字体，宽松行距，克制阴影。

批准此设计并开始制作 选择后，我将先写一份简短设计记录，再开始生成 HTML 和 PDF 成品。
